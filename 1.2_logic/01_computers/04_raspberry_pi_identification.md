| Component | Function |
|-----------|----------|
| SoC | Combines important computer components, such as the cpu, gpu and other controllers, into a single chip, it process instuction and controls the Raspberry Pi. |
| GPIO | provides the pins that allows the Raspberry Pi to connect and communicate with external electronic devices such as sensors, LEDs motors and buttons. |
| USB |  Allows to connect external devices like Keyboard, mouse, usb deives and other peripherals |
| HDMI | Sends digital video and audio singals from the Raspberry pi to a monitor, television or other display|
| Power | Supplies electrical energy to the Raspberry Pi so that all its components can operate correctly.  |
| microSD | Provides storage for the operating system, application, programs and user files |
| Network | Allows the Rasperry pi to connect to wired network using an ethernet cable to access the internet and communicate with other devices. |
| Wireless | provides wireless connectivity through Wi-fi and Bluetooth, allowing the Raspberry pi to connect to the internet and other wireless devices without cables. |

## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**.

Many componets are integrated into a single board in embedded computers like the Raspberry pi to make the device smaller, cheaper and more efficiently. Having componetnts together reduces the need for extra cables and separate hardware. It also saves space and make installation easier.Integarted components can communicate faster and use less power, which improves overall performance. This design is useful for projects involving robotics, automation, smart homes and the internet of things. It also makes the respberry pi affordable and portable, allowing students, developers and hobbyists to build different electronic projects easily.
