# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---
Hardware is the physical parts of a computer system that we can see and touch. It components are keyboard, mouse, monitor, motherboard, processor, cpu, Ram, hard drive and printer. Each hardware component performs a specific task. For example, the monitor display results, cpu processes instruction, keyboard is used to enter the information. With hardware only, a computer can be physically operate.
 
## Explain Software

For example, software include windows, microsoft word, Google chrome, and antivirus programs, software hepls users to performs activities like writing documents, browsing the internet, playing games and managing data.
